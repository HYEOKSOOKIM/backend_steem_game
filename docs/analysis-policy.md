# Backend Analysis Policy

## 1. 범위

- 단일 게임 리포트 중심의 오프라인 분석 시스템
- 사용자 경로는 조회 전용(read-only)

## 2. 분석 원칙

- 한국어 단일 언어 중심
- 저품질/욕설-only/비한국어 중심 리뷰는 분석 제외, 메타데이터는 보존
- 멀티 라벨 분류 기본
- 규칙 판정/LLM 판정/최종 판정의 추적 가능성 유지

## 3. 실행 원칙

- 수집/전처리/집계/LLM fallback은 오프라인 파이프라인에서만 실행
- 사용자 요청 경로에서 Steam API/LLM 실시간 호출 금지
- 재분석은 수동 실행

## 4. LLM 정책

- LLM은 애매한 subset fallback 용도로만 사용
- MVP에서 단일 통합 점수에 의존하지 않음

## 5. 품질 원칙

- 정확성 > 단순성 > 유지보수성 > 관심사 분리
- 정책/기능 변경 시 관련 문서와 테스트를 함께 갱신

# Backend Category Taxonomy

## 1. 목적

카테고리 체계를 내부 분류 기준과 사용자 노출 기준으로 분리해 유지한다.

## 2. 내부 분류 카테고리(고정)

- 플레이 경험: `gameplay`, `story`, `graphics`, `customization`
- 진입/학습: `difficulty`, `controls`
- 기술 안정성: `performance`, `bugs`, `save_progression`
- 장기 가치: `content_depth`, `mod_support`, `building_ux`
- 멀티/밸런스: `multiplayer`, `balance`
- 가격/현지화: `monetization`, `localization`

## 3. 사용자 노출 4축

1. 나에게 맞는가
2. 지금 사도 되는가
3. 후회 가능성
4. 오래 할 가치

## 4. 노출 원칙

- 내부 라벨을 그대로 제목에 노출하지 않는다.
- 반드시 `강점`/`리스크`를 분리한다.
- 저빈도 단일 의견보다 반복 근거를 우선한다.

## 5. 금지 라벨 처리

분류형 문구(`~문제`, `~불만`, `DLC/확장팩 언급` 등)는 경험형 문장으로 치환한다.
